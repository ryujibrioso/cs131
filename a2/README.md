# Clean Up Temp Files Script
### Overview
This script deletes all temp files (like .tmp, .log, and .bak files) 
in a directory.

### Why/When This Command Is Useful
This command is useful for deleting temporary files that might be taking up unnecessary space
within your computer or are unused.

### How to Use This Command
type the command name and the path to whatever directory you want to delete temp files in

For example, to delete temp files in your cs131 directory 
cleanup_temp ~/cs131

### Output
Usage: cleanup_temp <directory>
Deletes all temporary files (.tmp, .log, .bak) in the specified directory

Temporary files cleanup completed in ~/cs131.
